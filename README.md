
# E-commerce Sales Data Analysis and Visualization

## Project Overview

This project analyzes e-commerce sales data using Python.
It focuses on data cleaning, sales analysis and data visualization.

## Objectives

- Load and explore the sales dataset.
- Clean missing and duplicate records.
- Analyze product-wise sales performance.
- Identify monthly sales trends.
- Compare regional sales performance.
- Create meaningful visualizations.
- Generate business insights.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset Description

The dataset contains the following columns:

- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales
